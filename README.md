# UptoSkills-VAPT-Assessment-Owasp-Zap
Authorized VAPT assessment using OWASP ZAP for web application security testing. Includes automated scanning, spidering, vulnerability analysis, findings, screenshots, and remediation recommendations documented during the cybersecurity internship.
UptoSkills VAPT Assessment - OWASP ZAP
Overview
This repository contains OWASP ZAP security assessment activities performed as part of an authorized Vulnerability Assessment and Penetration Testing (VAPT) exercise.

The objective was to identify common web application security issues, analyze attack surfaces, validate findings, and provide security recommendations.

OWASP ZAP (Zed Attack Proxy)
Kali Linux
